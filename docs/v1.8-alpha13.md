# FrameByNavin v1.8 Product Alpha 13

Alpha 13 closes the creator lifecycle after publishing so the app behaves more like a creator operating system and less like a collection of screens.

## Locked behavior

- Existing Alpha 12 journey remains: Capture -> Ideas -> Create -> Insights.
- Completing the final workflow stage routes into Insights.
- When ideas already exist, the creator stays in Insights to review the completed cycle before choosing what to make next.
- When the idea pool is empty, Quick Capture opens after publishing so the next creator cycle can begin immediately.
- The loop remains deterministic and offline-first with no required backend or paid AI.
