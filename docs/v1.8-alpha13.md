# FrameByNavin v1.8 Product Alpha 13

Alpha 13 closes the creator lifecycle after publishing so the app behaves more like a creator operating system and less like a collection of screens.

## Locked Alpha 13 behavior

- Publishing/completing the final workflow stage still routes into Insights.
- If the creator already has ideas, the loop favors reviewing Insights before choosing the next project.
- If there are no ideas available, the app immediately opens Quick Capture so the creator can seed the next cycle.
- The next-loop policy is deterministic and offline-first; no backend or paid AI dependency is introduced.
- Existing Alpha 12 navigation remains intact: Capture -> Ideas -> Create -> Insights.
