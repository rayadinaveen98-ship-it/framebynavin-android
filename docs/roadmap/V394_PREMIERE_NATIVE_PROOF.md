# V394 — Backlot Premiere: native reminder experience proof

Status: **experimental source implementation; owner QA pending**. Branch is stacked on six-stage PR #377. No production merge or release approval is implied.

## Product intent

Replace the entire reminder presentation, not just the Canvas wallpaper: cinematic film-gate lighting, aperture/sunrise/progress hero motifs, native motion choreography, expressive typography, context and native controls. One visual language serves Creator, Personal and a 21-day concept.

This is an **engineering proof**, not a claim of final visual quality. It needs real-device screenshot/motion review before we decide whether the artwork and animation meet the founder's premium quality bar.

## Actual scope

- **Creator voice/alarm**: an opt-in complete native Compose Premiere layout. Reuses exact Stage Done / I'm Working / Snooze / Pause / Reschedule / Replay / Dismiss callbacks. Classic particle intro and V391 backgrounds remain intact when Premiere is off.
- **Personal voice/alarm**: the same opt-in experience, with existing Done / Snooze / Dismiss callbacks, loading/invalid/error handling, and unchanged locked-screen fallback. Personal NOTIFICATION mode continues using the legacy presentation.
- **21-day Challenge**: a **preview-only sample** with illustrative Day 08/21 progress. It is not connected to actual challenge state, does not alter delivery, and does not launch automatically from a notification. A production challenge surface needs its own authenticated/occurrence-validated navigation contract.
- **Settings**: Appearance > Reminder scenes adds separate voice/alarm Premiere switches and five safe full-screen previews. Both switches default OFF. V391 choices are neither rewritten nor deleted.
- **Artwork**: fully original procedural 2D Compose Canvas with bounded native drawing, no new remote asset dependencies, shader runtimes, subscriptions or paid services.
- **Audio**: no change to Creator/Personal playback, challenge TTS, music, audio focus, alarms or notification policies. Challenge voice+music remains a separate researched follow-up.
- **Privacy/data**: no changes to backup/restore/delete, user data schemas, reminder persistence, scheduling, lockscreen flags, widgets, companions, account state or existing notifications.

## Architecture

`V394PremierePrefs`: isolated opt-in booleans for Voice and Alarm.

`V394PremierePresentationPolicy`: testable guard for Creator and Personal, plus explicit challenge auto-launch prohibition.

`V394PremiereReminderScreen`: stateless presentation; callbacks remain owned by existing controllers. Art is non-interactive and cannot intercept touch. Scrollable controls and reduced-motion fallback are always available, even during entrance animation.

`V394PremiereAtmosphere` + `V394PremiereHero`: shared cinematic stage composition with category-specific motifs. Uses `V336MotionTime` for bounded lifecycle-aware animation. Power saver reduces effects; disabled Android animations freeze decorative motion.

`V394PremiereSettingsSection`: owner opt-in and safe previews, appended after existing V391 selectors.

## Known gaps and next decisions

- The proof uses procedural lighting/film motifs. It may require bespoke optimized artwork and motion refinement to meet the intended cinematic polish.
- Challenge currently has no new production full-screen route, and its preview Day 08 is intentionally illustrative.
- Voice + background music for challenge is not implemented.
- This is not a final replacement of the seven V391 backgrounds. They remain available for classic screens.
- No automated screenshot instrumentation or real-device validation has been performed by source commits alone.

## Release decision

Keep PR draft. Approve a production rollout only after owner visual review, Android build/signing verification, privacy and callback QA, and any necessary refinement. Do not merge or distribute as a production update without explicit founder sign-off.
