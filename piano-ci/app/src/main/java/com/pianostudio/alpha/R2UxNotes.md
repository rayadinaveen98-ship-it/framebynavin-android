# Alpha 0.3R2 UX rules

- Portrait is for browsing: Studio Home, Learn, Songs, Profile, Settings.
- Landscape is for playing: Lessons, Free Piano, Smart Practice, Performance, Create.
- Playing surfaces have one shared responsive scaffold.
- Keyboard receives the majority of usable landscape height.
- No fixed 320dp piano heights.
- No duplicate internal home screens after entering a playing mode.
- No Alpha/version/debug copy in user-facing Home or player UI.
- Guided learning hides punitive metrics until enough input exists.
- Small landscape phones show fewer, wider white keys; larger displays show more.
- Playing surfaces remain fixed; supporting sheets may scroll, the keyboard does not.
